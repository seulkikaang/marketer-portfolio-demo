# AgentBase 빌드 프롬프트 모음 (v2 — 팩트체크 반영, 복붙용)

데모 계정에서 아래 프롬프트를 순서대로 붙여넣는다. `[ ]`는 상황에 맞게 수정.
원칙: **한 프롬프트 = 한 가지 일**. AgentBase는 빌드 전에 확인 질문을 몇 개 던지므로 소요시간에 문답 시간을 포함할 것. **한 대화당 시스템 1개** — 다음 시스템은 홈으로 나가서 새 대화로.

> ⚠️ 팩트체크 반영 사항
> - "레코드 추가 시 실행" 트리거는 **존재하지 않음** (트리거는 스케줄/이메일 2종뿐) → 1-4를 무대용(채팅 지시)과 상시용(스케줄 배치)으로 분리
> - 폼의 **공개 링크(비로그인 제출)는 공식 지원** → 1-3에서 공개 링크 발급
> - 워크플로우 **Test Run은 시뮬레이션**(실발송·데이터 수정 없음) → 설정 검증용으로만 사용

## 데모 1. 트렌드 레이더 시스템

### 1-1. 트렌드 DB 생성 (trend_db.csv 업로드와 함께)

```
숏폼 트렌드 레이더 시스템을 만들어줘.
첨부한 trend_db.csv를 "트렌드 DB" 테이블로 가져와.
컬럼 타입: 7일 성장률은 퍼센트 숫자, 수집일은 날짜, 플랫폼·카테고리·단계·제작 난이도는 선택 옵션으로.
```

### 1-2. 대시보드 생성 (사전 준비 — 무대에서는 수정 명령만)

```
트렌드 DB로 대시보드를 만들어줘.
- 7일 성장률 상위 10개 트렌드 랭킹 (내림차순)
- 플랫폼별(틱톡/릴스/쇼츠) 트렌드 수 차트
- 카테고리별 분포 차트
- "급상승" 단계만 모은 섹션
상단에 마지막 수집일을 크게 표시해줘.
```

### 1-3. 리드 테이블 + 공개 폼

```
"방문자 리드" 테이블을 만들어줘. 첨부한 visitor_leads.csv 구조를 그대로 사용해.
이 테이블의 Form 뷰를 만들어줘. 폼 필드는 4개만:
- 채널 링크 (필수)
- 플랫폼 (선택: 유튜브 쇼츠/릴스/틱톡)
- 이메일 (선택)
- 개인정보 수집·이용 동의 (필수 체크)
폼 안내 문구: "공개된 유튜브 채널 링크를 권장합니다. 맞춤 트렌드 추천을 이메일로 보내드립니다.
입력하신 정보는 트렌드 추천 발송 목적으로만 사용하며 행사 종료 후 30일 내 파기됩니다.
서비스 제공을 위해 해외 서버(Genspark)에 저장됩니다."
접수 상태를 관리할 수 있게 "발송 상태" 컬럼을 추가하고 기본값은 "대기"로 해줘.
관리용 필드인 "발송 상태"는 공개 폼에서 숨김 처리해줘.
그리고 이 폼의 공개 링크(계정 없이 제출 가능한 링크)를 발급해줘.
```

발급된 공개 링크로 QR 포스터 제작. 태블릿·방문자 폰 모두 이 링크 사용.

### 1-4A. 무대용 파이프라인 (Super Agent 채팅에 라이브로 지시)

폼 제출 확인 후 사회자가 채팅에 입력하는 문장 (리허설에서 문구 고정):

```
방문자 리드 테이블에서 방금 접수된(발송 상태가 "대기"인 가장 최근) 채널을 분석해줘.
1단계: 채널 링크에 방문해 채널명, 최근 콘텐츠 주제를 수집하고
2단계: 채널의 카테고리, 콘텐츠 톤, 주 시청층을 분석한 다음
3단계: 트렌드 DB에서 카테고리와 시청층이 맞는 트렌드를 대조해서
4단계: 가장 적합한 트렌드 3개를 추천 이유, "첫 3초 훅 아이디어"와 함께
"추천 결과" 테이블에 저장해줘. 각 단계 진행 상황을 보여줘.
```

### 1-4B. 상시 운영용 배치 워크플로우 (30분 간격 — 트리거 대체)

```
30분마다 실행되는 워크플로우를 만들어줘.
방문자 리드 테이블에서 발송 상태가 "대기"인 레코드를 모두 찾아서, 각 레코드마다:
1) 채널 링크를 분석해 카테고리·톤·시청층을 파악하고
2) 트렌드 DB와 대조해 맞춤 트렌드 3개를 골라 추천 결과 테이블에 저장하고
3) 이메일이 있으면 추천 리포트를 Gmail로 발송한 뒤
4) 해당 레코드의 발송 상태를 "완료"로 바꿔줘.
대기 레코드가 없으면 아무것도 하지 마.
```

상태 갱신(4번)이 중복 발송 방지 장치다. 활성화 전 Test Run으로 설정만 검증하고(실발송 안 됨), 실제 동작은 테스트 리드 1건을 넣고 다음 실행 주기에 확인.

### 1-5. 매일 자동 갱신 (예약 워크플로우)

```
매일 오전 6시(Korea time)에 실행되는 워크플로우를 만들어줘.
유튜브 쇼츠와 인스타그램 릴스에서 최근 24시간 내 떠오르는 한국 숏폼 트렌드를 리서치해서
트렌드 DB에 새 행으로 추가하고, 기존 트렌드의 7일 성장률과 단계를 갱신해줘.
```

무대에서는 설정 화면 + 'Next Run At' + 실행 이력 패널(상태·시각·소요시간)을 보여준다. 라이브 발화가 필요하면 커스텀 간격(30분마다)으로 타이밍을 맞추되 목요일 리허설에서 발화 정확도 검증.

### 1-6. 추천 리포트 이메일 (수동 발송 데모용)

```
추천 결과 테이블에서 [채널명]의 추천 3건으로 맞춤 트렌드 리포트 이메일을 작성해서
[방문자 이메일]로 Gmail 발송해줘. 제목: "[채널명]님만을 위한 이번 주 트렌드 추천 3선"
본문에는 추천마다 트렌드 설명, 추천 이유, 첫 3초 훅 아이디어를 넣고,
마지막에 "이 시스템을 직접 만들어보고 싶다면" 섹션으로 [진단 에이전트 링크 또는 레시피]를 붙여줘.
```

사전 조건: Settings에서 데모 전용 Gmail 계정 연동 완료 (미연동 시 발송 실패 — 공식 명시).

### 무대용 라이브 명령 (공식 시연에서 검증된 패턴 — 리허설에서 문장 고정)

```
쇼츠만 보여줘                          ← 필터형 (공식 예시와 동일 유형)
막대 차트를 퍼널로 바꿔줘                ← 공식 런칭 시연 문구
카테고리별 비중 차트를 추가해줘           ← 공식 런칭 시연 문구 유형
정렬 기준을 7일 성장률로 바꿔줘
급상승 단계인 트렌드만 카드로 보여줘
```

⚠️ 채팅 명령은 에이전트가 5단계 플랜(Thinking→Verifying)을 돌아 수십 초 걸린다. 0초 반응이 필요하면: **차트 요소 클릭 → 하위 테이블 자동 필터**(공식 지원), 뷰 전환은 툴바 원클릭(무료·즉각).

## 데모 2. 1인 크리에이터 수출입 정리 시스템 (3분 카운트다운 쇼)

```
1인 크리에이터의 수출입 관리 시스템을 만들어줘.
첨부한 creator_trade_ledger.csv를 "거래 대장" 테이블로 가져와.
뷰 4개:
1) 전체 거래 대장 (거래일 최신순)
2) 수입/수출 구분 칸반 보드
3) 월별 손익 대시보드 — 원화 환산 기준 수입 지출/수출 매출 합계와 차트
4) "통관 대기이거나 정산이 안 끝난 거래"만 모은 확인 필요 뷰
[+ 관객 즉석 요구사항 1개를 여기에 추가]
```

라이브 명령:

```
관세 납부 대기인 건만 보여줘
이번 달 수출 거래의 원화 환산 금액을 합쳐줘
7월에 일본이랑 한 거래만 보여줘
```

## 데모 3. 인플루언서 협업 프로젝트 일정 관리

```
인플루언서 협업 프로젝트 관리 시스템을 만들어줘.
첨부한 influencer_collab_projects.csv를 "프로젝트" 테이블,
collab_tasks.csv를 "태스크" 테이블로 가져오고, 프로젝트ID로 두 테이블을 연결해줘.
뷰: 1) 현재 단계별 칸반 2) 업로드 마감일 캘린더 3) 인플루언서별 그룹 4) 상태 "지연" 필터
```

라이브 명령 (뷰 전환 원클릭 먼저 → 채팅 명령):

```
이번 주 마감인데 아직 초안 제작 단계인 프로젝트 보여줘
지연된 프로젝트 담당 매니저에게 보낼 리마인드 메일 초안 써줘   ← 초안 검토 화면에서 멈출 것 (발송 X)
```

옵션 피날레: Speakly Agent Mode로 위 명령을 음성으로 (화요일 한국어 인식률 테스트 통과 시에만).

## 커스텀 슈퍼 에이전트 — "내 채널 트렌드 진단 에이전트" (이메일 CTA용)

Custom Super Agent 생성 화면에서:

```
이름: 내 채널 트렌드 진단 에이전트
지침: 사용자가 유튜브/인스타그램 채널 링크를 보내면
1) 채널의 카테고리, 콘텐츠 톤, 주 시청층을 분석하고
2) 최신 숏폼 트렌드를 리서치해서
3) 이 채널에 맞는 트렌드 3개를 추천 이유·첫 3초 훅 아이디어와 함께 제시해줘.
결과는 표로 정리하고, 마지막에 다음 업로드 일정 제안을 붙여줘.
예시 프롬프트: "https://youtube.com/@[채널명] 이 채널에 맞는 트렌드 추천해줘"
```

공유 링크 발급 후 **비로그인/타 계정에서 접속 테스트**(화요일 §8 검증 항목). 통과 시 리포트 메일과 QR 포스터에 "지금 바로 써보기" 버튼으로.

## 옵션. 여행 플래너 (AI Developer에 입력)

```
제주 3박 4일 여행 플래너 웹앱을 만들어줘.
- 날짜별 타임라인, 일정 카드에 시간·장소·메모·예산
- 카드 등장 스크롤 애니메이션, 호버 마이크로 인터랙션
- 파스텔 톤 감성 디자인, 모바일 대응
- 상단에 D-day 카운터
- 일정 추가/수정 가능
```

앱은 사전 제작·다듬기(첫 결과물 품질 편차 있음). 무대에서는 **Publish 클릭 → 공개 URL 생성 → 청중 폰 접속**만 라이브 — 검증된 저위험 장면.
