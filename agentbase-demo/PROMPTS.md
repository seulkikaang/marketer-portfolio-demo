# AgentBase 빌드 프롬프트 모음 (복붙용)

데모 계정에서 아래 프롬프트를 순서대로 붙여넣으면 된다. `[ ]` 부분은 상황에 맞게 수정.
원칙: **한 프롬프트 = 한 가지 일**. 길게 몰아서 시키면 결과가 불안정하다.

## 데모 1. 트렌드 레이더 시스템

### 1-1. 트렌드 DB 생성 (CSV 업로드와 함께)

```
숏폼 트렌드 레이더 시스템을 만들어줘.
첨부한 trend_db.csv를 "트렌드 DB" 테이블로 가져와.
컬럼 타입: 7일 성장률은 퍼센트 숫자, 수집일은 날짜, 플랫폼·카테고리·단계·제작 난이도는 선택 옵션으로.
```

### 1-2. 대시보드 생성 (사전 준비 — 무대에서는 변형 명령만)

```
트렌드 DB로 대시보드를 만들어줘.
- 7일 성장률 상위 10개 트렌드 랭킹 (성장률 내림차순)
- 플랫폼별(틱톡/릴스/쇼츠) 트렌드 수 차트
- 카테고리별 분포 차트
- "급상승" 단계만 모아 보여주는 섹션
상단에 마지막 수집일을 크게 표시해줘.
```

### 1-3. 리드 테이블 + 입력 폼

```
"방문자 리드" 테이블을 만들어줘. 첨부한 visitor_leads.csv 구조를 그대로 사용해.
이 테이블에 새 항목을 추가하는 입력 폼을 만들어줘.
폼 필드는 "채널 링크"(필수), "플랫폼"(선택: 틱톡/릴스/쇼츠), "이메일"(선택) 3개만.
폼 안내 문구: "공개된 채널 링크를 입력해 주세요. 맞춤 트렌드 추천을 보내드립니다."
```

### 1-4. 4단계 추천 파이프라인 워크플로우

```
"방문자 리드" 테이블에 새 항목이 추가되면 실행되는 워크플로우를 만들어줘.
1단계: 입력된 채널 링크에 방문해서 채널명, 팔로워 수, 최근 콘텐츠 주제를 수집
2단계: 수집한 정보로 채널의 카테고리, 콘텐츠 톤, 주 시청층을 분석
3단계: 트렌드 DB에서 이 채널과 카테고리·시청층이 맞는 트렌드를 대조
4단계: 가장 적합한 트렌드 3개를 골라 각각 추천 이유와 "첫 3초 훅 아이디어"를 작성해서
"추천 결과" 테이블에 저장
각 단계가 끝날 때마다 진행 상황을 표시해줘.
```

### 1-5. 매일 자동 갱신 (예약 워크플로우)

```
매일 오전 6시에 실행되는 워크플로우를 만들어줘.
틱톡, 인스타그램 릴스, 유튜브 쇼츠에서 최근 24시간 내 떠오르는 한국 트렌드를 리서치해서
트렌드 DB에 새 행으로 추가하고, 기존 트렌드의 7일 성장률과 단계를 갱신해줘.
```

### 1-6. 이메일 발송 자동화

```
방문자 리드에 이메일이 입력되면, 그 방문자의 추천 결과 3건을 정리한 리포트와
이 트렌드 레이더 시스템을 그대로 만들 수 있는 안내를 담아
Gmail로 발송하는 자동화를 만들어줘. 발신은 [데모 계정 Gmail].
```

### 무대용 라이브 명령 (리허설에서 문장 확정 후 그대로 사용)

```
정렬 기준을 7일 성장률로 바꿔줘
쇼츠만 보여줘
다시 전체 플랫폼 보여줘
급상승 단계인 트렌드만 카드로 보여줘
```

## 데모 2. 1인 크리에이터 수출입 정리 시스템

```
1인 크리에이터의 수출입 관리 시스템을 만들어줘.
첨부한 creator_trade_ledger.csv를 "거래 대장" 테이블로 가져와.
뷰 4개를 만들어줘:
1) 전체 거래 대장 (거래일 최신순)
2) 수입/수출 구분 보드
3) 월별 손익 대시보드 — 원화 환산 금액 기준 수입 지출/수출 매출 합계와 차트
4) "통관 대기이거나 정산이 안 끝난 거래"만 모은 확인 필요 뷰
```

라이브 명령:

```
관세 납부 대기인 건만 보여줘
이번 달 수출 거래의 원화 환산 금액을 합쳐줘
7월에 일본이랑 한 거래만 보여줘
```

## 데모 3. 인플루언서 협업 프로젝트 일정 관리

```
인플루언서 협업 프로젝트 관리 시스템을 만들어줘.
첨부한 influencer_collab_projects.csv를 "프로젝트" 테이블,
collab_tasks.csv를 "태스크" 테이블로 가져오고, 프로젝트ID로 두 테이블을 연결해줘.
뷰: 1) 현재 단계별 칸반 보드 2) 업로드 마감일 캘린더 3) 인플루언서별 그룹 뷰 4) 상태가 "지연"인 프로젝트 필터
```

라이브 명령:

```
이번 주 마감인데 아직 초안 제작 단계인 프로젝트 보여줘
지연된 프로젝트 담당 매니저에게 보낼 리마인드 메일 초안 써줘
```

```
제주 3박 4일 여행 플래너 웹앱을 만들어줘.
- 날짜별 타임라인으로 일정 표시, 일정 카드에 시간·장소·메모·예산

- 상단에 여행 D-day 카운터와 날씨 위젯 느낌의 장식 요소
- 일정 추가/수정 가능하게
완성되면 공개 링크로 배포해줘.
```
